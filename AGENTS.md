# AGENTS.md — curso OpenCode EDteam

Curso-taller de OpenCode (mayo 2026). No es un proyecto productivo.

## Estructura

| Directorio | Qué contiene |
|------------|-------------|
| `pokedex/` | Proyecto del curso — React 19 + Vite 8 (ver `pokedex/AGENTS.md`) |
| `slides/` | Deck de diapositivas (Excalidraw `.excalidraw`, HTML) |
| `slides/quiz/` | Cuestionarios HTML autónomos de cada módulo |
| `assets/` | Prompts listos para copiar/pegar durante las clases |

- `pokedex/` es el único proyecto ejecutable (tiene `package.json`).
- El resto del workspace es contenido del curso — no modificarlo.

## Ignorados por git

- `guiones/` — guiones locales del instructor
- `/.idea/` — config IDE JetBrains
- `.DS_Store`

## Referencia

- `assets/prompts-modulo-1.md` — comandos y prompts del Módulo 1
- `assets/prompts-modulo-2.md` — comandos y prompts del Módulo 2
